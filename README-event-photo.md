# Фото автоматической афиши

Для карточек Evenementen.nl бот не использует рекламные изображения агрегатора.
Он извлекает официальный сайт конкретного мероприятия из detail-page, открывает его
обычным HTTP-запросом и берёт Event.image / og:image / релевантное hero-фото.
Если официальный сайт или достоверное фото не найдено, карточка остаётся без фото.
Это не вызывает Anthropic API и выполняется один раз для сохранённой месячной афиши.
