# Nederland 2027 — выбранный календарь (v1)

Алекс выбрал **предыдущий светлый вариант с фото и полезными подсказками слева и сеткой справа**.
Не использовать отклонённую концепцию «здесь живём», панорамный баннер или Unbounded.

## Сборка для Claude

Из корня репозитория, Python 3.12:

```bash
python3 -m venv .venv-calendar
.venv-calendar/bin/python -m pip install -r calendar_print/design_v1/requirements.txt
.venv-calendar/bin/python calendar_print/design_v1/build_calendar.py
.venv-calendar/bin/python -m unittest discover -s calendar_print/design_v1 -p 'test_*.py'
```

На Windows вместо `.venv-calendar/bin/python` используйте `.venv-calendar/Scripts/python.exe`.

Результаты в `calendar_print/design_v1/output/`:

- `Nederland-2027-new-design.pdf` — обложка, 12 месяцев, задняя страница; A4 **альбомный**, 297×210 мм.
- `Nederland-2027-bleed-3mm.pdf` — 303×216 мм, вылеты 3 мм, TrimBox 297×210 мм.
- `page-01.png` … `page-14.png` — визуальный контроль каждой страницы.
- `layout-checks.json` — проверки переполнения ячеек и боковых колонок; violations должен быть пуст.

Сверху 21 мм свободны под переплёт. Текст и сетка векторные; Onest/Rubik встроены.
Chromium, Playwright, ключи API, Telegram и запущенный бот для сборки не нужны.
Фотографии и variable-шрифты берутся из существующего `calendar_print/assets/`.
Статические начертания автоматически создаются локально в `.font-cache/`; интернет при сборке не нужен.

## Что именно воспроизводится

Это **воспроизводимый дизайн-образец**, а не новый production-генератор заказов:

- регион schoolvakanties **Zuid**;
- розовая «Ваша дата · пример» 18 апреля — демонстрация, не дата пользователя;
- QR открывает `https://t.me/podslushano_nl_bot`, не выдуманный личный заказ;
- данные для точного воспроизведения зафиксированы в `data-original.json`;
- исходный snapshot: `calendar_print/calendar_2027.json`, blob `6d65f7a96f78c77053959637f7c4cf6f177e2b00`;
- изменения подписей и тексты находятся в build_calendar.py (EV / CONTENT).

README и скрипт намеренно не обещают, что заказ автоматически персонализируется.
Не подключать этот specimen напрямую к оплате: это подменит личные даты примером и регион на Zuid.
