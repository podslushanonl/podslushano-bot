# Ручная редакция «Выгодно в NL»
- Администратор в личном чате текущего бота: /deals_post → текст или одна фотография с подписью → кнопки строками «Название | https://ссылка» (до 4) или «Без кнопок» → предпросмотр → «Опубликовать».
- /deals_cancel отменяет черновик. Черновики в памяти и не переживают перезапуск. Текст и форматирование сохраняются копированием Telegram. Публикация тихая.
- JSON-редакция: необязательный photo_url (публичный прямой HTTPS URL оригинального изображения), HTML с фото до 1000 символов; старые пакеты совместимы.
- Никаких изменений платежей, подписок, маршрутов доступа, конфигурации канала. Проверка администратора и подтверждённого канала обязательны. При неоднозначной ошибке отправки проверить канал вручную; не повторять вслепую.
- Перед слиянием: regression tests, smoke test импорта роутера, тест preview/cancel/confirm с фото, без фото, с кнопкой и без неё; подтвердить развертывание существующего бота. До этого команда в production не считается доступной.
