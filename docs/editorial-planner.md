# Планировщик авторов

Мост не меняет webhook Telegram, платежи, рекламу или публичное меню бота.
По умолчанию отправка напоминаний и API-запросы отключены.

## Подключение после публикации Site API

В Railway добавить переменные без кавычек:

```text
EDITORIAL_PLANNER_URL=https://podslushano-editorial.alex-podslushano.chatgpt.site
EDITORIAL_PLANNER_TOKEN=<секрет подключения из настроек кабинета>
```

Не вставлять секрет в код, ссылки, команды или сообщения Telegram.
После развёртывания кода автор сначала входит в кабинет по приглашению Алекса,
затем открывает профиль → «Подключить Telegram» и отправляет выданную команду
`/planner_link CODE` **в личные сообщения** боту. Код действует 10 минут.
Профиль и роль определяет Site; передать чужой `authorId` через команду нельзя.

Напоминания включаются автором в профиле кабинета. Их отправка ботом в личные
сообщения возможна только после того, как автор сам начал диалог с ботом.

## Команды

- `/planner` — кнопка входа в кабинет.
- `/planner_post` — только для `ADMIN_IDS`: один пост с кнопкой в текущем чате.
  Пост можно закрепить вручную. Команда ничего не публикует в других чатах.
- `/task Название` — добавить свою задачу.
- `/idea Название` — сохранить идею.
- `/direction Название` — добавить направление в рамках прав на Site.
- `/planner_link CODE` — одноразово связать Telegram и профиль кабинета.

Описание задачи или идеи можно дописать со следующей строки.
Для команды в группе, если Telegram этого требует, используется суффикс имени
бота: `/task@podslushano_nl_bot Название`.

## API и доставка

POST `${EDITORIAL_PLANNER_URL}/api/telegram`, заголовок
`Authorization: Bearer ${EDITORIAL_PLANNER_TOKEN}`, JSON:

```json
{"action":"bind","code":"...","telegramId":123,"telegramName":"Ксюша"}
{"action":"create","telegramId":123,"kind":"task","title":"Снять рынок","description":"..."}
{"action":"reminders"}
{"action":"ack","id":"..."}
```

Site проверяет токен, связывает Telegram, назначает автора и проверяет права.
Очередь `reminders` содержит только напоминания участникам, давшим согласие:
`{items:[{id,telegramId,text,url}]}`. Один проход обрабатывает не более 20 записей.
Фоновый цикл проверяет очередь раз в 5 минут только при обеих переменных.
После успешной отправки бот сохраняет маркер в своей существующей БД и вызывает
`ack`. Если подтверждение недоступно, повторяется подтверждение без повторной
отправки. Ошибки или блокировка бота не считаются успешной доставкой.

Как у любой пары удалённых сервисов, абсолютная однократность доставки при
аварии между отправкой Telegram и записью в БД не гарантируется. В обычном
режиме повторную доставку предотвращают маркеры и стабильные ID очереди.

Бот не передаёт учётные данные в URL и не следует HTTP-перенаправлениям при
запросе API. Ссылки из ответа ограничены origin настроенного планировщика.
