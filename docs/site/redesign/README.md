### Одна база для сайта и бота

Сейчас специалисты живут в базе бота (SQLite) и отдаются сайту фидом
`/api/specialists.json` (`utils/webserver.py`). Предлагаемая схема:

- База: PostgreSQL на Railway вместо SQLite (общие ID, параллельные записи сайта и бота).
- Каталожные сущности (специалисты, события, места, объявления, выходы AlloWalks,
  подписки) хранятся в этой базе и отдаются через один API.
- Бот и сайт работают только через этот API — без копий данных.
- Длинные тексты (новости, гайды, истории) — решается после аудита WordPress:
  остаются в WordPress (REST API) или переезжают в ту же базу.

При 5 часах в неделю модерация объявлений и подтверждение контактов должны
идти из бота кнопками «Одобрить / Отклонить», как сейчас работают заявки.

## КонтактGuide: одна карточка вместо копий по провинциям

В `seeds/specialists_seed.py` 287 строк, но это 89 карточек: 71 локальная и 18 онлайн-специалистов,
каждый из которых продублирован во всех 12 провинциях (18 × 12 = 216 строк).

База бота уже хранит онлайн-специалиста одной записью (`Specialist.is_online`, схлопывание в
`database/db.py::_desired_seed_rows`), а `/api/guide.json` отдаёт его с `prov: "онлайн"`. Правило
для нового сайта и кабинета:

- **Зона работы — свойство карточки, а не копия.** `local` = одна провинция и город;
  `nationwide` = вся страна онлайн (`is_online = true`, без провинции).
- **Выдача по провинции:** сначала локальные карточки провинции, затем отдельным блоком
  «Онлайн по всей стране». Счётчик провинции считает только локальные.
- **«Все»:** каждая карточка один раз.
- **Покупка размещения во всех провинциях** = переключение карточки в `nationwide`, а не создание
  12 записей. В кабинете это переключатель «В своей провинции / Вся NL онлайн».
- Если появится тариф «несколько провинций», добавляется список `service_provinces` у той же
  записи; копии не создаются.

## Правила v6

- Все анкеты (карточка, объявление, кабинет) принимаются только на русском языке: украинские буквы (і, ї, є, ґ) и текст преимущественно латиницей отклоняются с подсказкой.
- Телефоны хранятся в E.164 и показываются единообразно: `+31 6 1234 5678`, `+380 67 123 45 67`. Местные `06…` переводятся в `+31`. Неверный номер не показывается («номер уточняется у специалиста»).
- Известный неверный номер в сиде: «Актерская терапия» — `+316685196291` (на одну цифру больше, чем положено нидерландскому мобильному).
- Кнопка «Связаться» показывает все контакты карточки: Instagram, Telegram, WhatsApp, сайт, почта, телефон, с официальными логотипами (simple-icons).
- Не пишем «вся NL», «в NL»: только «по всей стране», «в Нидерландах».
- Виджет на телефон: PWA-страница `/now` и «На экран Домой». Нативный виджет требует приложения; данные NS требуют ключа NS API.

## Правила v7

- Лосёнок одевается по погоде (`docs/site/redesign/mascot/m-*.webp`): дождь → дождевик, морось/ливни → сапоги, ветер ≥ 6 Bft → худи, ≤ 6° → пальто и шарф, ≥ 22° → шорты, ясно днём → очки. Показывается на странице погоды, в карточке погоды на главной и в виджете.
