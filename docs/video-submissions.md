# Видео подписчиков: поток и Make

## Пользовательский поток

Прямая ссылка: `https://t.me/<bot_username>?start=video`.

1. Пользователь отправляет видео только документом/файлом без сжатия, до 200 МБ.
2. Бот собирает описание места и происходящего.
3. Пользователь указывает Instagram или имя для авторства.
4. Бот фиксирует согласие на редактирование и публикацию.
5. Пользователь проверяет карточку и отправляет её на модерацию.

## Модерация

Под карточкой доступны четыре действия:

- `Опубликовать в Instagram` — передать видео и подпись в Make;
- `Добавить в контент-банк` — сохранить для публикации позже;
- `Уточнить у автора` — продолжить диалог через бота;
- `Отклонить` — закрыть заявку и уведомить автора.

Контент-банк открывается в `Админ-центр → Контент → Видео подписчиков`.

## Webhook Make

В Railway нужно задать `VIDEO_MAKE_WEBHOOK_URL` с адресом отдельного custom
webhook Make. Не следует использовать webhook каруселей: структура данных другая.

Бот отправляет JSON:

```json
{
  "type": "user_reel",
  "source": "podslushano_telegram_bot",
  "submission_id": 77,
  "video_url": "https://<railway-domain>/submission-video/<random-token>",
  "telegram_file_id": "...",
  "caption": "Готовая подпись для Reels",
  "context": "Что снято и где",
  "credit": {"type": "instagram", "value": "@author"},
  "media": {
    "duration": 18,
    "width": 1080,
    "height": 1920,
    "mime_type": "video/mp4"
  },
  "consent": {
    "accepted": true,
    "version": "video-instagram-v1",
    "accepted_at": "2026-09-13T09:00:00+00:00"
  }
}
```

В Make используется `video_url` как исходный файл, `caption` как подпись Reels.
Webhook должен вернуть HTTP 2xx только после успешного принятия задания. При
ошибке статус заявки в боте не меняется, поэтому публикацию можно повторить.

Облачный Telegram Bot API позволяет скачать файл через `getFile` только до
20 МБ. Оригиналы размером 20–200 МБ бот принимает, хранит и пересылает в
контент-банк без повторной загрузки и сжатия, но для их автоматической выгрузки
в Make потребуется Local Bot API или внешнее объектное хранилище. Официальное
описание ограничения: <https://core.telegram.org/bots/api#getfile>.
