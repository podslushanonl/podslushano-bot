# podslushano — мобильное приложение

Expo (React Native), один код для iPhone и Android. Контент берётся с сайта
(`/wp-json/pn/v1/app` — новости, афиша, вакансии), сервисы — из бота (`/api/ns/*`, `/go/*`).

## Запуск

```bash
cd mobile
npm install
npx expo start          # QR-код для Expo Go на телефоне
npx expo start --web    # в браузере
```

Проверки перед коммитом: `npx tsc --noEmit` и `npx expo lint`.

## Этапы

1. Основа: лента, афиша, поезда NS, «Ещё» (готово); вход и личный кабинет, push-уведомления, виджеты.
2. Чаты по городам и темам, посты пользователей в ленте, модерация.
3. Объявления «купить/продать» с чатом с продавцом.
4. Германия и Бельгия.
