# Сбор на работу команды и сервисы · €500

Изменения ограничены существующим блоком поддержки и отдельным модулем WordPress. Оплата и код бота не изменены. Цель — один сбор €500, без автоматического обнуления.

## Установка

1. Соберите тему: `python3 wordpress/build_theme.py`. Загрузите полученный архив темы в WordPress обычным способом.
2. Откройте **Поддержка сообщества → Настройки сбора**. Установите фактическую дату начала сбора. По умолчанию это дата первого запуска обновления.
3. Укажите live API key того же профиля Mollie, через который принимаются донаты. Предпочтительный вариант: константа `PN_DONATION_MOLLIE_KEY` в `wp-config.php`; также доступно поле ключа в настройках. Ключ не передаётся посетителям и не включается в архив.
4. Нажмите **Сохранить и обновить**. Проверьте реальное пожертвование в списке вкладов и сумму на главной. Автоматическая сверка идёт через WP-Cron примерно раз в пять минут при посещениях; открытая страница запрашивает данные раз в минуту.

## Какие платежи учитываются

Только live-платежи EUR со статусом `paid`, созданные с даты начала сбора, с адресом возврата на главную Podslushano.nl с `?donation=thanks` — этот маркер уже используется существующим интерфейсом. Его соответствие реальным платежам нужно проверить после подключения ключа: обработчик бота в этой задаче не читался и не изменялся.

Для донатов по отдельным ссылкам Mollie добавьте их API ID `pl_…` в настройки. Это должны быть ссылки исключительно для поддержки, не для продаж. Публичный адрес `payment-links.mollie.com/payment/…` не является API ID.

Повторные импорты не создают повторных вкладов. Возвраты и оспоренные суммы вычитаются. Тестовые, неоплаченные платежи и платежи в других валютах исключены. При ошибке Mollie шкала сохраняет последние данные и сообщает о задержке. Сканирование постраничное; при большой истории оно продолжается в следующем запуске.

Регулярные списания без указанного адреса возврата или разрешённого `paymentLinkId` нельзя надёжно отличить от других оплат без изменения интеграции бота. Они не импортируются автоматически. Их можно учесть вручную либо отдельно подключить обработчик донатов бота.

## Вклады и благодарности

Автоматические поступления появляются анонимно. Чтобы опубликовать имя, получите согласие человека на публикацию имени и суммы, откройте соответствующий вклад, впишите имя в заголовок и отметьте согласие. Банковские реквизиты и email не публикуются.

Для подтверждённых переводов вне Mollie: **Поддержка сообщества → Добавить подтверждённый вклад**, сумма, дата получения, галочка подтверждения, публикация. Не добавляйте этот же платёж повторно вручную, если он уже импортирован. Чтобы отменить ручную запись, снимите подтверждение.
