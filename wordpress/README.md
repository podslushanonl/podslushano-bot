# Тема WordPress podslushano.nl 2026

Новый сайт podslushano.nl как тема WordPress. Платные плагины не нужны.

## Что внутри

- Все страницы прототипа с нормальными адресами: `/news/`, `/guide/`, `/events/`, `/events/<событие>/`, `/live/`, `/allowalks/`, `/shop/`, `/provinces/`, `/work/`, `/place/`, `/business/`, `/contact/`, `/travel/`.
- `/links/` — отдельная страница для Instagram (шаблон `page-links.php`), партнёры и афиша в `data/links.json`.
- Записи WordPress — это новости и статьи (статьи — рубрика «Статьи», slug `stati`). Каждая запись открывается по своему адресу в новом дизайне.
- Города, провинции и учреждения пишутся по-голландски (Amsterdam, Zuid-Holland, KVK). Поиск понимает и русские варианты: «амстердам» найдёт Amsterdam.
- Остальные страницы WordPress (Imprint, Privacy и т. д.) показываются в новом дизайне со своим текстом.
- Живые данные:
  - погода Buienradar, обновление раз в 10 минут, кэш в WordPress;
  - специалисты из бота (`/api/specialists.json`), раз в 15 минут;
  - поезда NS из бота, раз в минуту в браузере.
  Если источник недоступен, показываются последние полученные данные.
- Оплаты через бота и Mollie:
  - подарочная карта allowalks — `/api/allo/v2/gift`;
  - размещение в КонтактGuide — `/ads/contact-guide/checkout`;
  - вклад в развитие — `/api/donate`: разовый или ежемесячный (подписка Mollie, отмена по ссылке из письма);
  - подарочную карту можно отправить в выбранный день: письмо уходит получателю в 09:00 по Амстердаму.
- Формы «Неделя в Нидерландах», «Узнать о новых прогулках» и «Связаться» сохраняются в WordPress: Инструменты → «podslushano: заявки», там же выгрузка в CSV. Сообщения из «Связаться» дополнительно приходят на почту администратора.
- Кабинет бизнеса `/cabinet/` работает на сайте: вход по ссылке на почту для счёта или через бота (`/start cabinet_web`). Правки текста и фото проходят модерацию, цвет, скрытие и удаление применяются сразу, продление оплачивается на сайте.
- Объявления о работе и жилье пока публикуются через бота.

## Установка на Vimexx

0. **Сначала обновить бота:** смёржить PR с API сайта, дождаться деплоя на Railway.
1. **Резервная копия.** Плагины → Добавить новый → «UpdraftPlus» (бесплатный) → Установить → Активировать → Настройки → UpdraftPlus → «Создать резервную копию». Либо в панели Vimexx (DirectAdmin): Softaculous → WordPress → «Backup».
2. **Тестовая копия (рекомендуется).** Панель Vimexx (DirectAdmin) → Softaculous или «WordPress Manager» → у сайта «Create Staging» / «Staging» → поддомен, например `staging.podslushano.nl`. Чтобы на тестовой копии работали оплаты, добавьте в Railway в переменные бота `SITE_EXTRA_ORIGINS=https://staging.podslushano.nl`.
3. **Загрузка темы.** Внешний вид → Темы → Добавить новую → Загрузить тему → `podslushano-2026.zip` → Установить → Активировать.
   - Если хостинг ругается на размер файла (архив около 30 МБ): Vimexx → DirectAdmin → «PHP Settings» (Select PHP version → Options) → `upload_max_filesize` и `post_max_size` = 64M.
   - Можно и без этого: распаковать архив и загрузить папку `podslushano-2026` в `wp-content/themes/` через Файловый менеджер.
4. **Постоянные ссылки.** Настройки → Постоянные ссылки → «Название записи» → Сохранить. Это обновит адреса `/guide/`, `/events/` и остальные.
5. **Новости.** Инструменты → «podslushano: импорт новостей» → «Импортировать новости». Подготовленные новости появятся как обычные записи с фото; дальше новости пишутся как обычные записи.
6. **Плагины.** Тема работает с теми, что уже стоят:
   - **Complianz** — если активен, тема не показывает свой cookie-баннер, «Настройки cookie» в футере открывают Complianz, видео YouTube учитывает его согласие (категория «Маркетинг»). Без Complianz работает баннер темы.
   - **Yoast SEO** — у страниц `/guide/`, `/events/` и других свои заголовок, описание и canonical; в карте сайта Yoast появляется `pn-pages-sitemap.xml`.
   - **Cache Enabler** — страницы с живыми данными (главная, погода, КонтактGuide и т. д.) не кэшируются, записи и обычные страницы кэшируются как раньше. Формы не зависят от кэша.
   - **Plausible** — считает все страницы, включая `/links/`.
   - **CoBlocks** теме не нужен; если старые записи его не используют, можно деактивировать.
7. **Страница /links/.** Уже есть на сайте, тема сама показывает её в новом дизайне (шаблон по адресу страницы `links`).
8. **Откат.** Внешний вид → Темы → активировать прежнюю тему. Записи и страницы не меняются.

## Сборка темы

```
python3 wordpress/build_theme.py
```

Берёт `wordpress/src/` (код и данные прототипа, картинки, шрифты, видео) и собирает `wordpress/theme/podslushano-2026/` и архив `wordpress/dist/podslushano-2026.zip`.

## Автоматические новости

Бот каждые 10 минут проверяет ленты NOS, отбирает новости, полезные русскоязычным жителям Нидерландов (транспорт, погода, жильё, деньги, здоровье, безопасность и т. д.; без политики, спорта и зарубежья), пишет короткую новость на русском и сразу публикует её на сайте в рубрике «Новости» (подрубрика по теме) с фото из статьи-источника и подписью «Фото: NOS». Администраторы получают в Telegram заголовок и ссылку.

При первом запуске всё, что уже есть в лентах, пропускается, публикуются только новости, вышедшие после запуска (не старше 6 часов). Работает, когда у бота заданы `WP_URL`, `WP_USER`, `WP_APP_PASSWORD` и `ANTHROPIC_API_KEY`.

Переменные бота в Railway (все необязательные):

- `SITE_NEWS_ENABLED` — `0` выключает автоновости (по умолчанию включены).
- `SITE_NEWS_INTERVAL` — как часто проверять ленты, в секундах (по умолчанию `600`).
- `SITE_NEWS_FEEDS` — RSS-ленты через запятую (по умолчанию NOS: algemeen, binnenland, economie).
- `SITE_NEWS_PER_RUN` — сколько новостей максимум за одну проверку (по умолчанию `2`).
- `SITE_NEWS_DAILY_MAX` — сколько новостей максимум за сутки по Амстердаму (по умолчанию `20`).
