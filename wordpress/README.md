# Тема WordPress podslushano.nl 2026

Новый сайт podslushano.nl как тема WordPress. Платные плагины не нужны.

## Что внутри

- Все страницы прототипа с нормальными адресами: `/news/`, `/guide/`, `/events/`, `/events/<событие>/`, `/live/`, `/allowalks/`, `/shop/`, `/widget/`, `/provinces/`, `/work/`, `/place/`, `/business/`, `/contact/`, `/travel/`.
- `/links/` — отдельная страница для Instagram (шаблон `page-links.php`), партнёры и афиша в `data/links.json`.
- Записи WordPress — это новости и статьи (статьи — рубрика «Статьи», slug `stati`). Каждая запись открывается по своему адресу в новом дизайне.
- Остальные страницы WordPress (Imprint, Privacy и т. д.) показываются в новом дизайне со своим текстом.
- Живые данные:
  - погода Buienradar, обновление раз в 10 минут, кэш в WordPress;
  - специалисты из бота (`/api/specialists.json`), раз в 15 минут;
  - поезда NS из бота, раз в минуту в браузере.
  Если источник недоступен, показываются последние полученные данные.
- Оплаты через бота и Mollie:
  - подарочная карта allowalks — `/api/allo/v2/gift`;
  - размещение в КонтактGuide — `/ads/contact-guide/checkout`;
  - вклад в развитие — платёжная ссылка Mollie.
- Формы «Неделя в Нидерландах», «Узнать о новых прогулках» и «Связаться» сохраняются в WordPress: Инструменты → «podslushano: заявки», там же выгрузка в CSV. Сообщения из «Связаться» дополнительно приходят на почту администратора.
- Объявления о работе и жилье, а также кабинет бизнеса пока ведут в бота.

## Установка на Vimexx

1. **Резервная копия.** Плагины → Добавить новый → «UpdraftPlus» (бесплатный) → Установить → Активировать → Настройки → UpdraftPlus → «Создать резервную копию». Либо в панели Vimexx (DirectAdmin): Softaculous → WordPress → «Backup».
2. **Тестовая копия (рекомендуется).** Панель Vimexx (DirectAdmin) → Softaculous или «WordPress Manager» → у сайта «Create Staging» / «Staging» → поддомен, например `staging.podslushano.nl`. Чтобы на тестовой копии работали оплаты, добавьте в Railway в переменные бота `SITE_EXTRA_ORIGINS=https://staging.podslushano.nl`.
3. **Загрузка темы.** Внешний вид → Темы → Добавить новую → Загрузить тему → `podslushano-2026.zip` → Установить → Активировать.
   - Если хостинг ругается на размер файла (архив около 36 МБ): Vimexx → DirectAdmin → «PHP Settings» (Select PHP version → Options) → `upload_max_filesize` и `post_max_size` = 64M.
   - Можно и без этого: распаковать архив и загрузить папку `podslushano-2026` в `wp-content/themes/` через Файловый менеджер.
4. **Постоянные ссылки.** Настройки → Постоянные ссылки → «Название записи» → Сохранить. Это обновит адреса `/guide/`, `/events/` и остальные.
5. **Новости.** Инструменты → «podslushano: импорт новостей» → «Импортировать новости». Подготовленные новости появятся как обычные записи с фото; дальше новости пишутся как обычные записи.
6. **Баннер cookie.** В теме есть свой. Если стоит Complianz или другой плагин cookie, его нужно деактивировать, чтобы не было двух баннеров.
7. **Страница /links/.** Уже есть на сайте, тема сама показывает её в новом дизайне (шаблон по адресу страницы `links`).
8. **Откат.** Внешний вид → Темы → активировать прежнюю тему. Записи и страницы не меняются.

## Сборка темы

```
python3 wordpress/build_theme.py
```

Берёт `wordpress/src/` (код и данные прототипа, картинки, шрифты, видео) и собирает `wordpress/theme/podslushano-2026/` и архив `wordpress/dist/podslushano-2026.zip`.
